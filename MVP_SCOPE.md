# MVP scope

Implemented: products, SQLite persistence, search/filter query support, CRUD service/API, CSV import with duplicate-SKU update detection, CSV export, basic markup/discount calculation, and a responsive vanilla product grid/editor.

Deferred: Excel import/export, variants API/UI, image upload, full grid/list/table switches, PDF export, tax/exchange engines, RBAC, and all explicitly excluded platform features.
