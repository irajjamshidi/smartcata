# Wattks Shop WordPress theme

پوسته‌ی RTL و سبک برای فروشگاه‌های برق آنلاین. این پوسته با WooCommerce سازگار است و در صورت فعال بودن آن، چهار محصول پرفروش را در صفحهٔ نخست نمایش می‌دهد؛ در غیر این صورت کارت‌های نمونه برای پیش‌نمایش طراحی نشان داده می‌شوند.

## نصب

1. پوشهٔ `wattks-shop` را در `wp-content/themes/` کپی کنید.
2. از بخش «نمایش ← پوسته‌ها»، **Wattks Shop** را فعال کنید.
3. WooCommerce را نصب/فعال کنید و منوی «منوی اصلی» را از بخش فهرست‌ها تنظیم کنید.

طراحی کاملاً واکنش‌گراست و بدون وابستگی به فونت، تصویر یا افزونهٔ غیرضروری اجرا می‌شود.
